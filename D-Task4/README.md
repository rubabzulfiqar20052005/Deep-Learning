Observation
PCA reduced the dimensionality of the dataset while preserving most of the important information.
The cumulative explained variance curve showed how many principal components were required to retain 95% of the variance.
The 2D PCA projection provided a visual representation of digit classes in a lower-dimensional space.
Applying PCA before K-Means reduced noise and redundancy in the data, often improving clustering performance.
Image reconstruction demonstrated that increasing the number of principal components improved image quality.
Reconstructions using 10 components were blurry, while 100 and 200 components preserved most of the original image details.


Conclusion

PCA is an effective dimensionality reduction technique that compresses data while retaining important information. It improves visualization, reduces computational cost, and can enhance clustering performance. Higher numbers of principal components produce better image reconstructions, whereas fewer components result in greater information loss but higher compression.
