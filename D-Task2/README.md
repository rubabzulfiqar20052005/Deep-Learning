Observation:

Different linkage methods produce different cluster structures.

Single Linkage may create long chain-like clusters and is sensitive to noise.
Complete Linkage forms compact and well-separated clusters.
Average Linkage provides a balance between single and complete linkage.
Ward Linkage usually gives the best clustering results because it minimizes within-cluster variance.

Based on the Silhouette Scores, the linkage method with the highest score produced the best cluster quality for this dataset. In this experiment, Ward Linkage generally performed better and created more compact clusters.
